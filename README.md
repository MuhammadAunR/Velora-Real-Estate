# Velora Estates

A premium, responsive real estate website designed to showcase properties, build trust, and generate customer inquiries.

## Overview

Velora Estates is a modern real estate website built for property agencies and real estate professionals. It provides an elegant online presence for showcasing properties, services, client testimonials, and contact information.

The design uses a navy, warm beige, and soft gold color palette to create a professional and premium real estate experience.

## Features

* Responsive design for desktop, tablet, and mobile
* Modern and premium real estate UI
* Hero section with clear calls-to-action
* Featured property listings
* Property categories
* Real estate services
* About agent/agency section
* Areas served
* Testimonials
* FAQ section
* Contact and inquiry form
* WhatsApp and call-to-action integration
* Smooth scrolling
* Modern animations and interactions
* SEO-friendly metadata
* Reusable component-based architecture

## Tech Stack

* Next.js
* React
* Tailwind CSS
* JavaScript
* Motion
* Google Fonts

## Getting Started

Clone the repository:

```bash
git clone https://github.com/MuhammadAunR/Velora-Real-Estate.git
cd velora
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser.

## Production Build

Create a production build:

```bash
npm run build
```

Run the production server:

```bash
npm start
```

## Customization

The website uses reusable components and data-driven sections, making it easy to customize for different real estate agencies, agents, properties, locations, and branding.

Update the relevant data files and replace the provided imagery and business information to adapt the website for a specific client.

This project was created as a real estate website concept and portfolio project, demonstrating modern frontend development, responsive design, reusable components, and conversion-focused UI.
